is only on windows so

extract the zip file and open the exe file named "main"

CONTROLS:

WAD for movement
S for dash roll
1/2/3/4 for the different weapons (Glock, Sniper, Shotgun, Knife)
Q throw the knife (when 4 is press)

not implemented/broken at the moment:
R for reloading the weapon

Welcome to Gunformer, an very early release platformer where powerups are replaced with GUNS?! and a... Knife? You will need to use your arsenal wisely to beat the auto generated levels, the most distance you make, the stronger the enemies are and remember, one hit and you are OUT!
